# Carolin Hartung — Personal Academic Website

Source code for my personal academic website.

**Website:** https://carolin-hartung.de

The website contains information about my mathematical research, publications, talks, and outreach activities.

The site is built with [Quarto](https://quarto.org/) and hosted on GitHub Pages.

## Local preview

```bash
quarto preview
```

## Publishing updates

```bash
quarto publish gh-pages
```
